# Complete classification of the sole-shared exceptional Cairo family

**Status: VALID**, assembled from separately independently reviewed exact proofs. This is a classification of one displayed one-parameter family under unrestricted contacts and all isometries. It is not a classification of all two-pentagon pairs or a solution to the original problem.

Let w=sqrt3>0 and1/w<r<2−1/w, t=2−r. Define the positive strictly convex Cairo pentagons with native side directions0,90,150,240,300 by

    P=(1,r,(3w−r)/2,(wr−1)/2,2),
    Q=((wt−1)/2,(3w−t)/2,t,1,2).

**Theorem.** The displayed pair admits a plane tiling if and only if r=1. At r=1 the two shapes are congruent and admit an explicit doubly periodic monohedral tiling. Thus every member having two distinct congruence classes is untileable and none solves the main target.

2. At r0 or2−r0, extra cross-arm matches invalidate the Q-cluster argument, but the [separate native-slot root obstruction](partial-contact-cairo-single-shared-exceptional-roots.md) is VALID. P clusters remain forced. Q notch fillers demand an impossible full Qc seam; P fillers have only their same-slot bank-sum-compatible mate and force strict original overlap. The [fresh root review](../reviews/partial-contact-cairo-single-shared-roots-review.md) independently reconstructs all native events and exact convex clipping.
3. At r=1, [the periodic monotiling](partial-contact-cairo-adjacent-repeat-periodic.md) uses eight original pentagons per cell, with periods(w,−w),(3w,3w) and covolume18. Exact native congruence, all relevant lattice translations and coverage were independently reviewed [VALID](../reviews/partial-contact-cairo-adjacent-repeat-periodic-review.md). Reflection reverses P's native side word to Q, so this exceptional point contains one congruence class, not two.

The positive interval is exactly the shapes' positive-length domain, and the three cases partition it. No continuity, solver deadline, bounded failed extension, imposed edge-to-edge rule or positive-frequency inference enters the classification. Stable replays and independent checkers are linked in the component lemmas. The original two-convex-tile problem remains unresolved.
