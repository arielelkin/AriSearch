# A periodic binary equality fibre has a periodic point whenever it has a point

Date: 2026-10-12. Status: [fresh hostile review VALID](../reviews/periodic-binary-equality-fibre-lifting-review.md).

Let a locally finite graph have vertex set Z^2 x V, with V finite, and
finitely many translation-invariant edge types. At each vertex choose one
bit. Each edge constraint has the form equality of two prescribed maps
{0,1}->S, where S is any set; the maps are periodic, as are any unary
constraints. If this system has an infinite solution, it has a solution
periodic under a finite-index subgroup of Z^2. No assertion about arbitrary
binary SFTs is made. A previously chosen finite-index periodic backbone can
be used as the base lattice by enlarging V.

## Reduction to a signed graph

A two-by-two equality table cannot have exactly three allowed pairs:
three equalities force the fourth by transitivity. Its possibilities are
empty, full, singleton, one row, one column, diagonal or antidiagonal.
An empty table excludes all solutions. A full table supplies no constraint.
A singleton supplies two pins; a row/column supplies one pin. Diagonal
and antidiagonal tables give b_u XOR b_v=s with s=0 or1. Unary constraints
are empty, a pin, or unconstrained. Thus it suffices to solve a periodic
signed graph with periodic pins. Assume an infinite solution exists.

## Closed-walk translation gains and parity

Take the finite quotient of the signed graph by Z^2. Consider each connected
component separately and choose a quotient root r and a spanning tree.
For any closed walk at r, record its translation gain t in Z^2 and XOR
of edge signs epsilon in Z/2. Reverse edges carry opposite gain and the
same sign. Concatenation adds both quantities. The set of all such pairs
is a subgroup Gamma of Z^2 x Z/2, finitely generated by the fundamental
cycles of the finite quotient graph. Repeated vertices and parallel/self
edges are allowed.

If (0,1) belonged to Gamma, a lifted closed walk would demand that a bit
be its own opposite. The assumed infinite solution excludes this. Hence
projection Gamma->Z^2 is injective. Write its image L<=Z^2 and write
Gamma={(t,chi(t)):t in L}, with chi:L->Z/2 a homomorphism.

There is an integer N>0 with N*Z^2 intersect L contained in 2L. Explicitly,
if L has rank zero take N=1. For rank one, write L=Z*(a,b) and let
d=gcd(|a|,|b|)>0; take N=2d. If k*(a,b) has both coordinates divisible
by N, Bezout gives N dividing k*d, so k is even. For rank two let
d=[Z^2:L] and take N=2d. Then d*Z^2 is contained in L, and every vector
of N*Z^2 belongs to 2L. Choose a common multiple of these N over the
finitely many quotient components and put K=N*Z^2.

In the finite graph quotient by K, every closed walk has gain in K and
hence in K intersect L, so its sign is zero. Thus every unpinned connected
component of this finite graph admits a bit assignment, propagated from
one arbitrary root bit without contradiction.

## Pins remain consistent

For two pinned vertices in the same connected component of the finite
K-quotient, lift a path between them to the infinite graph. Its endpoints
are translates of the corresponding pinned native vertex types. Pins
are invariant under all base translations, so the assumed infinite
solution implies that the path sign is exactly the XOR of their prescribed
bits. Consequently every pair of pins in each finite component is
consistent. Propagate from any pin; components without pins use an
arbitrary root bit. Lifting this finite assignment gives a K-periodic
solution satisfying every original edge and unary constraint. QED.

## Polygon application and limitations

This applies when a periodic angle/colour backbone leaves at most two full
native placements at each tile, and the only remaining constraints are
native side-length equalities across seams. A singleton fibre is represented by a pinned bit (or duplicated as two
identical maps); every equality table has the specified form, including
reflections and coincident length values. The
result gives periodic full placement labels, rather than merely periodic
colours. A separately reviewed polygon-development theorem is still needed
to convert those labels into a periodic Euclidean tiling.

The finite cover is derived from signed-cycle translation gains; it is not
inferred from failure of a bounded torus search. Twice the base period need
not suffice: a signed edge connecting translates separated by two lattice
steps can require four steps. No periodic lifting theorem is asserted for
fibres of three or more placements, for arbitrary binary constraints, or
for a backbone that has not itself been proved periodic.
