# Five-direction height screen for unit Robinson source clusters

**Status:** exact complete integer enumeration with a [VALID fresh independent audit](../reviews/pentagrid-robinson-height-boundary-review.md). The [source-height analytic formalization](../lemmas/pentagrid-robinson-source-height-and-stokes.md) has its own distinct VALID fresh review. This is a new necessary source-legality test, not
an existence proof or a rejection of every source compiler.

The tested parent coordinates and unit triangle scales are those in
[pentagrid-golden-metric-robinson-partitions.md](pentagrid-golden-metric-robinson-partitions.md).
The hypothesized source is an actual edge-to-edge unit Penrose rhomb tiling,
cut along the specified thin short and fat long diagonals. No arbitrary
unmarked triangle tiling is assumed to lift to the same five-dimensional
height lattice.

## Finite domain and encoding

With z=exp(pi*i/5), lift z^k to E_k in Z^5 for k=0,...,4, and
z^(k+5) to -E_k. A rhomb face has a zero lifted boundary, so its simply
connected locally finite plane cellulation has a global vertex height map.
The source diagonal lifts are

    u*z^k -> E_k,
    l*z^k -> E_(k-1)+E_(k+1),
    s*z^k -> E_(k-2)+E_(k+2),

where u=1,l=phi,s=phi^-1 and signed indices are modulo10. Physical
projection has kernel generated by R=(1,-1,1,-1,1). A boundary of an actual
source cluster must close in Z^5, rather than merely close after projection.

The exact ordered word domains are unchanged:625 U boundaries and21801 V
boundaries. All rotations and reflections of the source triangle corners
remain allowed. There is no coordinate cutoff, symmetry reduction, solver,
stochastic seed, or timeout. The script uses exact Python integer arithmetic
in Conda arisearch/Python3.12.13; it imports the existing author word/fan
producer, so this replay alone is not an independent implementation.

For U, the lift is (n_s0+n_s1-1)*R; for V it is
(3-n_s1-n_s3-n_s4)*R. Thus source legality forces total short-diagonal
counts1 and3, boundary edge counts10 and13, and triangulated-disk interior
vertex counts4 and7, respectively. These are necessary counts only.

For a closed height boundary with successive vertices H_j, form

    Q=sum_j H_j wedge H_(j+1).

Interior triangle edges cancel. Every positively oriented specified unit
triangle contributes exactly one positive basis wedge E_i wedge E_j with
i<j. Hence Q's ten integer coefficients are the numbers of triangles in
the ten unordered source direction pairs. Pairs with j-i=1 or4 are thin;
the remaining pairs are fat. Nonnegative coefficients and the exact
contents7thin/9fat or9thin/16fat are necessary. The factor is one rather
than one-half: physical projection of Q is twice ordinary triangle area.

## Replay and next discriminating check

    conda run --no-capture-output -n arisearch python research/searches/pentagrid-robinson-height-boundary.py

The [producer](pentagrid-robinson-height-boundary.py) prints JSON and writes no
files. Assertions must remain enabled. Exact certificate replays compare
parsed JSON in memory.

The next concrete test is source diagonal completion: each boundary diagonal
forces its unique adjacent triangle inside the parent. Its apex is
x+z^(k+2) for a short diagonal and x+z^(k+1) for a long diagonal.
Containment, overlap and the parity of paired interior diagonals may reject
surviving boundaries. This is a geometrically new source constraint, not an
increase of the timed-out pentagon macro count. The height test itself
excludes neither parent; the plane existence and periodic-lift obligations
remain open.
